## Acceptance use

The slice is accepted only when every row has a rendered state label, deterministic test evidence for complete and incomplete data, and no unverified field is represented as live. The later single-field on-demand plan must separately prove one centroid, one source, request/run IDs, timeout/rate behavior, latest-good/cache, persistence/history, freshness, and Copilot trace. The focused 33-test component receipt, narrow field-detail 1/1 browser receipt, and final deterministic 5/6 browser receipt are the observed evidence for this correction pass. Hydrology evidence is split explicitly: the standalone package command produced both 64/64 and 63/64 across fresh runs; root parallel `pnpm test` produced 63/64; the serialized `--test-concurrency=1` command also produced 64/64 and 63/64. The failure is the pre-existing 25 ms retry-timing test at `http-clients.test.ts:128`, not a UI acceptance failure. The unchanged `Snapshot stale detectado` production-smoke failure, API limitation, historical `government-ui.spec.js:78` note, and skipped live-provider check remain outside the deterministic pass rather than being reported as passed.

## Scope boundary assertions

- `GET /agronautas/ready` is dependency/runtime readiness only; it is not an on-demand acquisition readiness result and does not claim a request ID, run ID, source, centroid, or persistence outcome.
- A later on-demand design remains a one-PR follow-on: it must prove one centroid, one source, request/run IDs, timeout/rate behavior, latest-good/cache, persistence/history, freshness, and Copilot trace, with external Postgres/Redis prerequisites. It must not infer Corrientes-wide feasibility.
- This change excludes Docker, Google Maps, WhatsApp, durable/editable polygons, scheduler/Risk Engine rewrites or consolidation, and hydraulic simulation claims. The current map seam remains unconfigured and point-only; field persistence stores coverage metadata, not a durable polygon.

The executable contract/scope assertions live in `apps/api/src/presentation/routes/health.test.ts` and `packages/contracts/tests/agronautas-contracts.test.ts`. They exercise the current readiness response, map seam, field persistence SQL, package dependencies, and the SDD scope documents; they do not assert mere artifact existence.
